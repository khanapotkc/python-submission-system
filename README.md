# ระบบส่งงานและดูคะแนน — การเขียนโปรแกรมคอมพิวเตอร์ ม.2 (2/2569)

เว็บแอป Google Apps Script ที่อ่าน/เขียนข้อมูลจาก Google Sheets 3 ไฟล์ของครูโดยตรง

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | Backend: เข้าสู่ระบบ, ดึงสถานะ+คะแนน, ฟังก์ชันจัดการของครู |
| `Index.html` | หน้าเว็บทั้งหมด (นักเรียน + Admin) ธีม Python |

## วิธีติดตั้ง (ประมาณ 5 นาที)

1. ไปที่ <https://script.google.com> → **โครงการใหม่** (ใช้บัญชี Google ที่เป็นเจ้าของ/แก้ไขชีตทั้ง 3 ไฟล์ได้)
2. ลบโค้ดเดิมใน `Code.gs` แล้ววางเนื้อหาจากไฟล์ `Code.gs`
3. กด **+ → HTML** ตั้งชื่อว่า `Index` (ตัว I ใหญ่) แล้ววางเนื้อหาจาก `Index.html`
4. เลือกฟังก์ชัน `testConnection` แล้วกด **เรียกใช้** → อนุญาตสิทธิ์ → ดู Log ว่าอ่านชีตได้ครบ
5. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
6. คัดลอก URL `/exec` ไปใช้ (ฝังใน Canva ด้วย Embed ได้)

> แก้โค้ดภายหลัง ต้อง **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** ทุกครั้ง URL จะคงเดิม

## การเข้าสู่ระบบ

- **นักเรียน**: กรอก **รหัสนักเรียนอย่างเดียว** (เช่น `05867`) — ระบบค้นจากคอลัมน์ Password ในชีต Login ถ้าไม่พบจะค้น STD_ID ในชีตสถานะ/คะแนน (พิมพ์ 0 นำหน้าหรือไม่ก็ได้)
- **ครู**: แท็บ `teacher.py` → ใช้บัญชีครูที่ได้รับแจ้ง (ในโค้ดเก็บเป็นค่า hash เท่านั้น) — หลังติดตั้ง Apps Script แนะนำให้ตั้งรหัสใหม่ที่ Admin › ตั้งค่า
- เปลี่ยนรหัสเริ่มต้นในโค้ด: คำนวณ SHA-256 ของ `username:password` แล้วใส่ใน `ADMIN_HASH` (Index.html) และ `DEFAULT_ADMIN_HASH` (Code.gs)

## ความสามารถหน้า Admin

- **ภาพรวม** อัตราการส่งรายงาน/รายห้อง, คะแนนเฉลี่ย, รายชื่อนักเรียนที่ค้างงาน
- **สถานะการส่ง** ตารางแก้ไข (ตรวจแล้ว / ส่งแล้ว / ส่งช้า / ส่งใหม่ / ยังไม่ส่ง) + เติมทั้งคอลัมน์ → กดบันทึกครั้งเดียว
- **คะแนน** กรอกคะแนนแบบตาราง เตือนเมื่อเกินคะแนนเต็ม
- **นักเรียน** เพิ่ม / แก้ไข / ลบ (อัพเดททั้ง 3 ชีตพร้อมกัน)
- **ภาระงาน** เพิ่มคอลัมน์งานใหม่ แก้ชื่อ/คะแนนเต็ม และใส่ **ลิงก์ส่งงาน** (นักเรียนที่ยังไม่ส่งจะเห็นปุ่ม "ไปส่งงาน")
- **ตั้งค่า** ประกาศถึงนักเรียน, เปลี่ยนบัญชีครู, ลิงก์เปิดชีตต้นทาง

### เครื่องมือของครูในหน้า Admin (เมื่อเชื่อมต่อ Apps Script แล้ว)

| แท็บ | ทำอะไรได้ |
|---|---|
| ภาพรวม | สถิติการส่งรายงาน/รายห้อง, นักเรียนที่ต้องติดตาม |
| สถานะการส่ง | แก้สถานะทุกช่อง, เติมทั้งคอลัมน์, ส่งออก CSV |
| คะแนน | กรอกคะแนน, ให้คะแนนเต็มกับคนที่ตรวจแล้วในคลิกเดียว, ส่งออก CSV |
| นักเรียน | เพิ่ม/แก้/ลบ (อัพเดท 3 ชีตพร้อมกัน), **นำเข้าหลายคน** (วางจาก Excel), ดูหน้าจอแบบนักเรียน, ส่งออก CSV |
| ภาระงาน | เพิ่ม/แก้ชื่อ/คะแนนเต็ม/ลบคอลัมน์, ลิงก์ส่งงาน, **กำหนดส่ง** (นักเรียนเห็น "เลยกำหนด"), คำอธิบายงาน |
| **แก้ไขชีต** | ตัวแก้ไขแบบ Spreadsheet ของทั้ง 3 ชีต — แก้ได้ทุกช่องรวมหัวตาราง, เพิ่ม/ลบแถวและคอลัมน์, วางข้อมูลหลายช่อง |
| ตั้งค่า | เชื่อมต่อ Apps Script, ประกาศ, ข้อมูลรายวิชา/หัวเว็บ/ตราโรงเรียน, ตัวเลือกสถานะ, เปลี่ยนรหัสผ่านครู |

## กติกาของชีต

- ระบบใช้ **แท็บแรก** ของแต่ละไฟล์ (เปลี่ยนได้ที่ `LOGIN_TAB / STATUS_TAB / SCORE_TAB` ใน `CONFIG`)
- หัวคอลัมน์งานควรเป็น `รหัส : ชื่อ` เช่น `W6 : nested if` — รหัส (ก่อน `:`) ใช้จับคู่ชีตสถานะกับชีตคะแนน
- คะแนนเต็มอ่านจากวงเล็บท้ายหัวคอลัมน์ในชีตคะแนน เช่น `W6 : nested if (5)`
- งานที่มีเฉพาะในชีตคะแนน (เช่น `Mid Test (20)`) จะแสดงเป็นการ์ด "การสอบ"
- ใส่ตราโรงเรียนได้ที่ `CONFIG.APP.logoUrl`

## โหมดการทำงานของ Index.html

| โหมด | เมื่อไร | ข้อมูล |
|---|---|---|
| **Apps Script** | ติดตั้งตามขั้นตอนด้านบน | อ่าน + เขียนชีตได้ครบ (แนะนำ) |
| **LIVE** | เปิด `Index.html` ตรง ๆ หรือโฮสต์เป็นเว็บธรรมดา (GitHub Pages, Netlify ฯลฯ) | ดึงข้อมูลจริงจาก 3 ชีตโดยตรง **อ่านอย่างเดียว** (ต้องแชร์ชีตแบบ "ทุกคนที่มีลิงก์ดูได้") |
| **DEMO** | เติม `?demo=1` ท้าย URL | ข้อมูลจำลอง (นักเรียน `00001`, ครู `demo` / `demo1234`) |

### เปิดโหมดแก้ไขบน GitHub Pages

1. ติดตั้ง Apps Script ตามขั้นตอนด้านบน (ข้อ 1–5) แล้วคัดลอก URL `/exec`
2. เข้าหน้า Admin บนเว็บ → ปุ่ม **เปิดโหมดแก้ไข** (หรือแท็บ ตั้งค่า) → วาง URL → **ทดสอบและเชื่อมต่อ** → เข้าสู่ระบบครูใหม่
3. หน้าเว็บจะส่งคำสั่งไปที่ Apps Script (`doPost`) ซึ่งเขียนลงชีตจริง — ป้ายมุมล่างเปลี่ยนเป็น **CONNECTED**
4. ให้ใช้ได้ทุกเครื่อง: ใส่ URL ในตัวแปร `API_URL` ของ `index.html` (นักเรียนก็จะดึงข้อมูลผ่าน Apps Script แทน จึงปิดการแชร์ชีตสาธารณะได้)

ID ของชีตในโหมด LIVE อยู่ที่ตัวแปร `SHEETS` ใน `Index.html` ส่วนโหมด Apps Script อยู่ที่ `CONFIG` ใน `Code.gs`

> ⚠ โหมด LIVE ทำงานในเบราว์เซอร์ทั้งหมด ข้อมูลชีตจึงเปิดดูได้โดยใครก็ตามที่มีลิงก์อยู่แล้ว (เพราะชีตแชร์สาธารณะ)
> และรหัสครูเก็บเป็นค่า hash — หากต้องการความปลอดภัยของข้อมูลนักเรียน ให้ใช้โหมด Apps Script แล้วปิดการแชร์ชีตสาธารณะ
